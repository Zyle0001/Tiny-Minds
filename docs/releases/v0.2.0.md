# Tiny Minds v0.2.0

Tiny Minds `0.2.0` is the first developer preview of the rebuilt cognitive-machinery runtime. It moves bounded work such as deterministic validation, retrieval, graph inspection, embedding comparison, classification, and narrow local inference out of frontier-model prompts while preserving evidence for the host agent.

## Highlights

- Portable Python 3.10+ core with no Foundry, Agentic Workspace, NumPy, `psutil`, or fixed-layout requirement.
- Declarative YAML pipelines with versioned schemas, budgets, cancellation, deterministic routing, and explicit degradation.
- Allowlisted extension API for third-party integrations and model providers.
- Typed embedding, reranking, NLI, and classification provider contracts.
- Ten implemented generic capabilities plus the mature Agentic Workspace memory validator.
- Separately packaged HTTP provider example that exercises every model protocol without Foundry.
- Sterile wheel tests and a six-job Windows, Linux, and macOS CI matrix.
- Metadata-only telemetry, bounded excerpts, and no hidden frontier-model fallback.

## Release boundary

This is a developer preview. The ten generic capabilities are implemented but remain experimental because their calibration fixtures have not yet received human review. They are not bootstrap-published and consuming skills must not invoke them automatically. The workspace memory validator remains the first published capability.

The next calibration milestone is the deterministic Phase 1 safety gate for:

- `workspace.validate-scoped-delta`
- `workspace.change-packet`
- `repo.preflight`

## Artifacts

The GitHub Release should include:

- `tiny_minds-0.2.0-py3-none-any.whl`
- `tiny_minds-0.2.0.tar.gz`
- `tiny_minds_example_http_provider-0.2.0-py3-none-any.whl`
- `tiny_minds_example_http_provider-0.2.0.tar.gz`
- `SHA256SUMS.txt`

Verify downloads from the artifact directory with PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 *.whl, *.tar.gz
```

Install the core wheel with:

```powershell
python -m pip install .\tiny_minds-0.2.0-py3-none-any.whl
tiny-minds doctor --json
```

The external provider is an integration example rather than a hosted production service. Install it alongside the matching core release when testing provider discovery.

## Compatibility

- Python 3.10 or newer.
- Apache-2.0 licensed.
- Foundry Local Runtime is optional and explicitly configured.
- PyPI publication is not required for this preview.
